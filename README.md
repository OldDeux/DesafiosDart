# Desafios de Programação em Dart

Este repositório contém a resolução de três desafios de programação utilizando a linguagem Dart, propostos na atividade da disciplina Linguagem Dart.

Os códigos foram desenvolvidos de forma simples, utilizando estruturas básicas da linguagem para facilitar o entendimento e a prática da programação.

## Desafios

### 1. Jogo da Forca
O jogador deve descobrir uma palavra secreta, tentando acertar uma letra por vez. O jogo termina quando a palavra é revelada ou quando o limite de erros é atingido.

**Arquivo:** `forca.dart`

### 2. Jogo da Velha
Jogo para dois jogadores, que alternam entre os símbolos X e O em um tabuleiro 3x3. O objetivo é formar uma linha com três símbolos iguais, na horizontal, vertical ou diagonal.

**Arquivo:** `velha.dart`

### 3. Jogo do Labirinto
O jogador controla um personagem representado pelo símbolo `@` e deve encontrar a saída do labirinto, evitando as paredes. A movimentação é feita por meio de comandos digitados no terminal.

**Arquivo:** `labirinto.dart`

## Tecnologias utilizadas

- Linguagem Dart
- Execução pelo terminal
- Estruturas condicionais (`if` e `else`)
- Estruturas de repetição (`while` e `for`)
- Listas e variáveis

## Como executar

É necessário ter o Dart SDK instalado e configurado no computador.

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto no terminal.
3. Execute o desafio desejado utilizando um dos comandos abaixo:

```bash
dart forca.dart
```

```bash
dart velha.dart
```

```bash
dart labirinto.dart
```

Cada arquivo pode ser executado de forma independente.

## Objetivo

Praticar os conceitos básicos de programação em Dart por meio da criação de jogos simples, desenvolvendo o raciocínio lógico e a utilização de estruturas fundamentais da linguagem.
